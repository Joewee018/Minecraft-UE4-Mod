# SM64 Steve Movement (mod:sm64)

A toggleable mod in the Mods menu (M). It gives the player Super Mario 64 style movement and draws them as a rigged,
animated Minecraft Steve. It works in any world and game mode, including Zombies maps and the superflat test world.
Turning it off returns the player to vanilla movement within one Minecraft tick.

## Where things live
| Part | File | Role |
|---|---|---|
| Physics | `Bridge/src/client/java/crb/client/sm64/Sm64Controller.java` | A 30 Hz SM64-style state machine on the client thread. It replaces `Player.travel` through `PlayerTravelMixin`. Collision and step-up use vanilla `Entity.move`, so the server validates the movement like vanilla walking. |
| Settings | `Sm64Config.java` | Tuning values plus the user settings, pushed by Unreal with the `sm64.config` op. |
| Input | `HostInput.java` | While SM64 drives, vanilla movement keys stay up. Java receives the raw stick, the camera yaw and the jump/crouch press counters. |
| No fall damage | `crb/Sm64Server.java`, `mixin/PlayerFallDamageMixin.java` | Applies to SM64-driven players unless the "Vanilla fall damage" setting is on. |
| Auto-jump | `mixin/LocalPlayerAutoJumpMixin.java` | Vanilla auto-jump is off while SM64 drives. |
| Rig and clips | `Avatar/blender/steve_build.py` (`Tools/SteveBuild.ps1`) | All original: the Minecraft player boxes (standard 64x64 skin UVs, outer layers, classic and slim arms), a 10-bone rig and 22 keyframed clips. |
| Import | `Unreal/Scripts/CreateSteve.py` | Imports into `/Game/Crb/Steve`. Run by `BuildUnreal.ps1` when `Work/steve/build` exists. |
| Presentation | `CrbSteve.*`, `CrbSteveAnim.*`, `CrbSm64.cpp` | Steve wears the live Minecraft skin. A native anim instance crossfades the clips by Java action, and the orbit camera follows Steve. |
| Menus | `CrbMenus.cpp` | The `mod:sm64` row, plus a settings page that is saved to the config ini. |
| Tests | `CrbTestSm64.cpp` | Run with `-CrbTest=sm64`; the suite is also part of `all`. |

## Moves
Controls are WASD (relative to the camera), Space (A), Shift (Z) and Ctrl (walk).

- **Walk and run:** speed builds to 32 units/frame. A turn-around skid triggers when you reverse at 16 or more.
- **Jump chain:** single, double, then triple jump. The triple needs speed above 20 when you jump on landing.
- **Side flip:** jump during a skid.
- **Backflip:** crouch, then jump.
- **Long jump:** run, crouch-slide, then jump.
- **Wall kick:** jump into a wall, then jump again within the window. Without the second jump you bonk off the wall.
- **Ground pound:** crouch in the air.
- **Hard landing:** happens on falls of more than 7 blocks.

Java hands control back to vanilla in water, lava, on ladders, while flying, while riding, while using an elytra, while sleeping and while dead.

Scale: 1 SM64 unit = 0.01125 blocks (Mario's height maps to Steve's). Speeds are in units per 30 Hz frame.

## Reference policy
The SM64 decompilation was read only to learn values and transitions, such as acceleration curves, jump velocities and windows. No code, models or animation data were copied.

## Not included
- Swimming, the slope-sliding physics and the steep-slope butt slide: Minecraft has no slopes.
- Punch, dive and kick: the attack button stays Minecraft's mine/attack.
- Ledge grabs.
